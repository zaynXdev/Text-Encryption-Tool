# Text Encryption Tool

A secure web-based text encryption tool supporting multiple encryption algorithms.

## Features

- **Encryption Algorithms**: Caesar Cipher, Base64, AES, SHA-256
- **Security**: Input validation, secure headers, error handling
- **User-Friendly**: Clean interface with real-time feedback
- **Export**: Download encrypted text as files

## Algorithms Implemented

1. **Caesar Cipher**: Simple substitution cipher with shift=3
2. **Base64**: Binary-to-text encoding scheme
3. **AES**: Advanced Encryption Standard (128-bit)
4. **SHA-256**: Secure Hash Algorithm 256-bit
